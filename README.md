🚀 Daily Productivity & Workspace Dashboard

A clean, modern, and responsive Daily Workspace & Productivity Engine designed for daily personal workflow management. Features real-time weather integration, an interactive habit tracker, pomodoro timer, task management, quick bookmarks, and an auto-saving scratchpad.
live link:

✨ Features

☀️ Hybrid Live Weather System:

Auto-fetches live weather data for any city using Open-Meteo API (No API Key required!).

Option to connect your custom OpenWeatherMap API Key in settings.

Live temperature, condition icons, humidity, and wind speed updates.

⚡ Daily Habit Tracker:

Add, track, and complete daily routines (e.g., drinking water, reading, exercising).

Dynamic progress bar showing completion percentage in real-time.

⏱️ Pomodoro Timer:

25-minute focus session timer with start, pause, and reset controls.

✅ Today's Tasks (To-Do List):

Instant task management with interactive completion status.

Persistent local storage memory.

📝 Quick Scratchpad:

Instant auto-saving note taking area for quick thoughts or phone numbers.

🚀 Quick Access Hub:

One-click shortcuts to frequently used platforms (Google, YouTube, GitHub, Gmail, ChatGPT, LinkedIn).

🕒 Dynamic Live Clock & Bengali Greeting:

Real-time time display with adaptive greetings based on the time of day.

🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript (ES6+)

Styling: Tailwind CSS CDN

Icons: Lucide Icons

Weather APIs:

Open-Meteo API (Default, Free & Keyless)

OpenWeatherMap API (Optional Custom Key)

Data Persistence: Browser localStorage API

🚀 Live Demo & How to Run

Method 1: Open Directly in Browser

Clone this repository or download the source code:

git clone https://github.com/YOUR_USERNAME/daily-productivity-dashboard.git


Navigate to the project folder and double-click index.html to open it in any web browser.

Method 2: Deploy to GitHub Pages (Free Hosting)

Go to your repository Settings on GitHub.

Click on Pages in the left menu under "Code and automation".

Under Branch, select main (or master) and save.

Your dashboard will be live at https://YOUR_USERNAME.github.io/daily-productivity-dashboard/.

⚙️ Weather Configuration

By default, the dashboard fetches weather for Rangpur using Open-Meteo without requiring any setup.

To customize:

Click the Settings (⚙️) icon in the Live Weather section.

Enter your desired City Name (e.g., Dhaka, Chittagong, London).

(Optional) Paste your personal OpenWeatherMap API Key.

Click Save & Refresh.
